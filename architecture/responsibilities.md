# Byngox Responsibilities

Byngox is the intelligence engine of Sorabbyngo OS.

Responsibilities

- Reasoning
- Planning
- Agent orchestration
- Task decomposition
- Long-term memory
- Context reasoning
- Capability selection
- Workflow execution

Byngox never communicates directly with hardware.
It delegates execution to operating system services.

Networking is delegated to Byngonet.
